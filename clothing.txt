Title: Multi-class Image Classification using Deep Neural Networks

Theory:
A Deep Neural Network (DNN) is applied here to computer vision to classify grayscale images into one of ten mutually exclusive categories (e.g., T-shirts, trousers, sneakers)[cite: 3].
Unlike text classification, where data is vectorized into one-hot arrays, image classification deals with 2D matrices of pixels, where each pixel has a numeric value indicating its intensity[cite: 3].
The Fashion MNIST dataset contains 70,000 such images (60,000 for training, 10,000 for testing), each standardized to a very low resolution of 28x28 pixels[cite: 3].
Before feeding these images into the network, the pixel values, which originally fall in the range of 0 to 255, must be scaled down to a range between 0.0 and 1.0[cite: 3]. 
This normalization step is critical because neural networks converge faster and perform better when the input data features are small and scaled consistently[cite: 3].
The first layer in our architecture is a Flatten layer, which transforms the 2D image matrix (28x28) into a single 1D array of 784 pixels, unstacking the rows without learning any parameters[cite: 3].
This 1D array is then passed into a fully connected, or Dense, hidden layer containing 128 artificial nodes (or neurons)[cite: 3].
These 128 neurons utilize the ReLU (Rectified Linear Unit) activation function to detect non-linear geometric patterns, edges, and features in the pixel data[cite: 3].
The final output layer is another Dense layer with exactly 10 nodes, corresponding to our 10 possible clothing categories[cite: 3].
This final layer returns a logits array with a length of 10, meaning it outputs raw, unscaled scores for each of the 10 classes rather than probabilities[cite: 3].
During training, the adam optimizer iteratively updates the network based on the data it sees, while the SparseCategoricalCrossentropy loss function measures accuracy to steer the model[cite: 3].
After training, we attach a Softmax layer to the trained model, which converts the raw linear outputs (logits) into a proper probability distribution that is easier to interpret[cite: 3].
We also evaluate the model on the test set to monitor for Overfitting, which is when a model memorizes the training data noise and performs worse on new, unseen inputs (represented by the gap between training and test accuracy)[cite: 3].

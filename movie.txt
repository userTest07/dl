Title: Movie Review Sentiment Analysis using Deep Neural Network (Binary Classification)

Theory:
A Deep Neural Network (DNN) is a powerful machine learning architecture used here for Natural Language Processing (NLP) to perform binary sentiment classification on movie reviews.
Unlike humans, neural networks cannot process raw text strings; they require numerical tensors to perform complex mathematical operations.
Therefore, the IMDB reviews are first preprocessed into sequences of integers, where each integer corresponds to a specific word's frequency ranking in a dictionary.
To feed this data into a densely connected network, these integer sequences must be transformed into uniform, fixed-size tensors using a process called One-Hot (or Multi-Hot) Encoding.
This vectorization process blows up each review into a sparse 10,000-dimensional binary vector, where a '1' signifies the presence of a word from our constrained vocabulary, and '0' signifies its absence.
The core architecture relies on fully connected, or Dense, layers, where every input is connected to every neuron in the subsequent layer through learnable weights and biases.
In this model, we utilize two hidden layers, each containing 16 neurons, which act as sophisticated feature detectors to learn complex, non-linear relationships between specific combinations of words.
To enable the network to learn these complex, non-linear patterns, we apply the Rectified Linear Unit (ReLU) activation function to the output of each hidden layer.
Mathematically, ReLU is defined as f(x) = max(0, x), which efficiently zeroes out negative values and helps mitigate the vanishing gradient problem common in deep network training.
The final output layer consists of a single neuron equipped with a Sigmoid activation function, designed to squash the network's final arbitrary numerical output into a strict probability range between 0.0 and 1.0.
An output closer to 1.0 indicates a high probability of positive sentiment, while an output closer to 0.0 indicates a negative sentiment, usually separated by a threshold of 0.5.
During the training phase, the network makes predictions, measures its error, and iteratively adjusts its internal weights using an optimization algorithm called RMSprop, which adapts the learning rate during gradient descent.
The error is quantified using the Binary Crossentropy loss function, which is the standard measure for two-class classification problems as it calculates the probabilistic divergence between the predicted score and the actual ground-truth label.
A critical challenge in training highly expressive deep neural networks is Overfitting, a phenomenon where the model begins to memorize the specific training data rather than learning generalized, overarching patterns.
Overfitting becomes visually apparent when the training loss continues to approach zero, but the validation loss begins to diverge and increase after a certain number of training cycles (epochs).
To combat this and ensure our model generalizes well to unseen, real-world data, we employ a technique called Early Stopping, where we intentionally halt the training process before the model over-optimizes on the training set.

Algorithm:
1. Import required libraries (NumPy, Keras, Matplotlib)
2. Load IMDB Dataset
   - Limit to top 10,000 most frequent words

   - Hidden Layer 1: 16 neurons, ReLU activation
   - Hidden Layer 2: 16 neurons, ReLU activation

5. Compile Model

   - Optimizer : RMSprop (learning_rate = 0.001)
   - Metric : Binary Accuracy

   - Split training data: 15,000 training samples, 10,000 validation samples

   - Epochs : 20
   - Batch size : 512
   - Plot Training vs Validation Loss and Accuracy to detect overfitting
8. Retrain Model
   - Stop training early at 3 epochs to prevent overfitting (identified from plots)
9. Evaluate Model & Make Predictions
   - Predict sentiment probabilities on 25,000 test sequences
   - Round continuous probabilities to binary 0 or 1
   - Calculate Mean Absolute Error (MAE) against true test labels

#Binary_Classification_IMDB_movie_reviews.py
# 1. Importing Packages & Loading Data: Import Keras, NumPy, and Matplotlib. Load top 10,000 frequent words.
import numpy as np
from keras.datasets import imdb
from keras import models
from keras import layers
from keras import optimizers
from keras import losses
from keras import metrics
import matplotlib.pyplot as plt
(train_data, train_labels), (test_data, test_labels) = imdb.load_data(num_words=10000)
train_labels[0]
print(type([max(sequence) for sequence in train_data]))
max([max(sequence) for sequence in train_data])
# 2. Decoding the Reviews: Reverse the integer-to-word dictionary to decode a sample review to English text.
word_index = imdb.get_word_index()
reverse_word_index = dict([(value, key) for (key, value) in word_index.items()])
decoded_review = ' '.join([reverse_word_index.get(i-3, '?') for i in train_data[0]])
decoded_review
len(reverse_word_index)
# 3. Preparing the Data (Vectorization): Convert integer sequences into 10,000-dimensional binary vectors (One-Hot Encoding).
def vectorize_sequences(sequences, dimension=10000):
    results = np.zeros((len(sequences), dimension))
    for i, sequence in enumerate(sequences):
        results[i, sequence] = 1.
    return results
X_train = vectorize_sequences(train_data)
X_test = vectorize_sequences(test_data)
X_train[0]
X_train.shape
y_train = np.asarray(train_labels).astype('float32')
y_test = np.asarray(test_labels).astype('float32')
# 4. Building the Network: Stack Dense layers (16 units, relu activation). Final layer uses sigmoid for 0-1 probability.
model = models.Sequential()
model.add(layers.Dense(16, activation='relu', input_shape=(10000,)))
model.add(layers.Dense(16, activation='relu'))
model.add(layers.Dense(1, activation='sigmoid'))
# 5. Compiling: Use RMSprop optimizer and binary_crossentropy loss function.
model.compile(optimizer=optimizers.RMSprop(learning_rate=0.001), loss=losses.binary_crossentropy, metrics=[metrics.binary_accuracy])
# 6. Validation Setup: Set aside 10,000 samples to monitor accuracy on unseen data during training.
X_val = X_train[:10000]
partial_X_train = X_train[10000:]
y_val = y_train[:10000]
partial_y_train = y_train[10000:]
# 7. Initial Training: Train for 20 epochs to observe when overfitting begins (usually around epoch 3-5).
history = model.fit(partial_X_train, partial_y_train, epochs=20, batch_size=512, validation_data=(X_val, y_val))
history_dict = history.history
history_dict.keys()
# Visualizing Loss: Plot Training vs Validation Loss to see the divergence.
loss_values = history_dict['loss']
val_loss_values = history_dict['val_loss']
epochs = range(1, len(loss_values) + 1)
plt.plot(epochs, loss_values, 'g', label="Training Loss")
plt.plot(epochs, val_loss_values, 'b', label="Validation Loss")
plt.title('Training and Validation Loss')
plt.xlabel('Epochs')
plt.ylabel('Loss Value')
plt.legend()
plt.show()
# Visualizing Accuracy: Plot Training vs Validation Accuracy.
acc_values = history_dict['binary_accuracy']
val_acc_values = history_dict['val_binary_accuracy']
epochs = range(1, len(loss_values) + 1)
plt.plot(epochs, acc_values, 'g', label="Training Accuracy")
plt.plot(epochs, val_acc_values, 'b', label="Validation Accuracy")
plt.title('Training and Validation Accuraccy')
plt.xlabel('Epochs')
plt.ylabel('Accuracy')
plt.legend()
plt.show()
# 8. Retraining & Evaluation: Stop early at 3 epochs to prevent overfitting, then evaluate on test data.
model.fit(partial_X_train, partial_y_train, epochs=3, batch_size=512, validation_data=(X_val, y_val))
np.set_printoptions(suppress=True)
result = model.predict(X_test)
result
# Fix shape error: Vectorize rounding and flatten the 2D prediction array to 1D to match y_test shape.
y_pred = np.round(result).flatten()
mae = metrics.mean_absolute_error(y_pred, y_test)
mae
